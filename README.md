# ShopProject — контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

**Полыковский Евгений Александрович, ЭФБО-04-25.**
Дисциплина: «Фронтенд и бэкенд разработка». Преподаватель: Загородних Николай Анатольевич.

Учебный интернет-магазин мерча 1С с интерактивностью на чистом JavaScript: массив товаров, генерация карточек, поиск, фильтрация, сортировка, корзина с промокодами и валидация формы. Проект создан на основе адаптивной HTML/CSS-версии из **КР №3** (`kr3-responsive-shop`) и продолжает её предметную область, вёрстку, тёмную тему и изображения. Bootstrap, сборщик и фреймворки не используются.

- Репозиторий: https://github.com/epolykovskiy/kr4-js-shop
- Опубликованная версия: https://epolykovskiy.github.io/kr4-js-shop/

## Локальный запуск

Из директории проекта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000/index.html. Установка npm-пакетов не требуется. Остановить сервер: Ctrl+C.

Формы демонстрационные: данные проверяются в браузере и не отправляются на сервер. Корзина, промокод и тема сохраняются в `localStorage`. При выключенном JavaScript страницы и ссылки остаются доступны, но каталог, корзина и проверка форм требуют JavaScript.

## JavaScript-файлы

- `data.js` — массив товаров `products`, карта категорий `categories`, промокоды `promoCodes` и функция `formatPrice`.
- `catalog.js` — сборка карточек `buildCard`, `initCatalog` (поиск, фильтр, сортировка) и `initPopularProducts`.
- `cart.js` — объект `Cart`: чтение/запись `localStorage`, добавление и удаление, количество, сумма через `reduce`, промокод и скидка.
- `modal.js` — `openQuickView` и `initQuickView`: модальное окно быстрого просмотра.
- `product-page.js` — `initProductPage`: формирует страницу товара по `?id=`.
- `validation.js` — `validation(form)`: проверка нативной валидности, вывод ошибок и фокус.
- `order-page.js` — `initOrderPage`: заполнение списка товаров и обработка формы заявки.
- `feedback-page.js` — `initFeedbackPage`: обработка формы обратной связи.
- `theme.js` — переключение темы через `data-theme` и `localStorage`.
- `main.js` — общая инициализация, мобильное меню, делегирование кликов «В корзину», уведомления `showToast`.

## Массив товаров

В `js/data.js` лежит массив `products` из 10 товаров. У всех одинаковая структура:

```js
{
  id: 1,                 // уникальный числовой идентификатор
  title: 'Тапочки меховые «1С»',
  category: 'shoes',     // ключ из categories
  price: 1000,           // число, не строка
  oldPrice: null,        // старая цена для скидки (или null)
  isAvailable: true,     // наличие
  image: 'images/tapchan.webp',      // изображения + srcset 320/640
  alt: 'Жёлтые меховые тапочки с логотипом 1С',
  description: 'Тёплые домашние тапочки с фирменным логотипом.',
  badge: 'hit'           // hit | new | discount | null
}
```

Категории (`categories`): `shoes` (Обувь), `socks` (Носки), `clothes` (Одежда), `accessories` (Аксессуары). Значения категорий совпадают со значениями фильтра в каталоге. Цены записаны числами, id уникальны.

## Реализованные функции

- **Генерация карточек** — карточки создаются через `createElement`, данные заполняются через `textContent`, классы через `classList`, карточки добавляются через `append`. В HTML карточки вручную не прописаны.
- **Поиск** — поле поиска реагирует на событие `input` и фильтрует по вхождению подстроки в `title`.
- **Фильтрация** — список категорий реагирует на `change`; дополнительно есть диапазон цен.
- **Сортировка** — по цене (возрастание/убывание) или названию (А–Я/Я–А); применяется к копии массива `[...filtered].sort(...)`, исходный порядок не меняется.
- **Пустое состояние** — при отсутствии результатов выводится сообщение и ссылка сброса фильтров.
- **Счётчик** — надпись «Найдено товаров: N» обновляется при каждом изменении.
- **Валидация формы** — на `order.html` проверяются обязательные поля, e-mail и телефон (`pattern`); ошибки выводятся рядом с полями через `textContent`, ставится `aria-invalid`, фокус переходит к первому ошибочному полю.
- **Сообщения** — ошибки и успешные сообщения выводятся на страницу (`role="status"`), а не через `alert()`.
- **Безопасный вывод** — пользовательские данные (названия, данные формы, содержимое корзины) выводятся только через `textContent`; `innerHTML` для пользовательских данных не используется.
- **События** — все обработчики подключены через `addEventListener` (`click`, `input`, `change`, `submit`); inline-обработчиков в HTML нет.

## Самостоятельные доработки

| Доработка | Реализация |
|---|---|
| Корзина | Добавление, удаление, изменение количества; счётчик в шапке |
| Расчёт суммы через `reduce` | `subtotal()` считает сумму позиций, `total()` — с учётом скидки |
| `localStorage` | Корзина, промокод и тема сохраняются между перезагрузками |
| Промокод/скидка | `MERCH10` (−10%) и `MERCH20` (−20%), пересчёт итога |
| Тёмная тема | `data-theme` + `localStorage`, сохранение выбора |
| Страница товара по `?id=` | `product.html` формируется из массива по параметру URL |
| Модальное окно товара | Быстрый просмотр по клику на изображение карточки |
| Улучшенная форма | Имитация отправки, понятное сообщение с товаром и количеством, сброс |
| Улучшения UX | Пустое состояние каталога и корзины, бейджи «Хит/Новинка/Скидка», старые цены, наличие |
| Структура кода | Логика разделена по файлам, функции названы осмысленно |

## Проверка в консоли

На страницах `index`, `catalog`, `product`, `order`, `contacts`, `feedback`, `cart` критических ошибок в консоли нет. Каждая страница подключает только нужные скрипты, а функции инициализации проверяются на существование (`typeof ... === 'function'`) и на наличие элементов, поэтому скрипт не падает, если элемент отсутствует на странице.

## Примечание об изображениях

Шесть исходных товаров используют фотографии из КР №1/№3. Для четырёх новых товаров (футболка, кружка, кепка, рюкзак «1С») используются честные изображения-заглушки, сгенерированные детерминированно (Pillow) в фирменной жёлтой гамме: это не генеративные фотографии. Все товарные изображения имеют варианты WebP шириной 320 и 640 px для `srcset`.

## Коротко для защиты

- `data.js` хранит массив объектов; массив удобен, потому что его легко перебирать, фильтровать и сортировать стандартными методами.
- `querySelector` находит элемент, `createElement` создаёт узел, `textContent` безопасно задаёт текст, `classList` управляет классами, `append` добавляет узел в DOM.
- `addEventListener` регистрирует обработчики; делегирование — один обработчик на родителе, который по `closest` определяет нажатую кнопку.
- `sort` применяется к копии массива, чтобы не нарушить исходный порядок данных.
- `textContent` не интерпретирует HTML, поэтому пользовательский ввод не может выполниться как разметка (в отличие от `innerHTML`).
- `preventDefault` отменяет стандартную отправку формы, после чего форма проверяется и показывается сообщение на странице.
- `localStorage` сохраняет корзину, промокод и тему; обращение обёрнуто в `try/catch`, чтобы отказ хранилища не ломал страницу.
